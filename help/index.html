Schedule Management App — Help & User Guides

Guides for everyone who uses the timetable: viewers, teachers, and administrators.

What this app is for. The IIIS Schedule Management App is the school’s shared weekly timetable for Green, Yellow, Purple, and Blue cohorts. It helps staff see who is teaching what, when, and where — and helps administrators keep that information accurate as people, days, and activities change.
Open Live Schedule

Purpose of the Schedule Management App

IIIS runs multiple cohorts in parallel. This app is the single place to:

  • See the school week by day, by cohort, school-wide, or by teacher
  • Reduce confusion about coverage, transitions, and overlapping duties
  • Support fair assignment of full-time and non-full-time Teacher-members
  • Give administrators a controlled way to update weeks, people, absences, and holidays
It is the operational timetable for the school week — not a lesson-planning tool and not an HR system.

Key terms

  • Cohorts: Green, Yellow, Purple, Blue
  • Assignment: an activity block with time, cohort, and people
  • Support: additional adults helping a block
  • Conflict: same person assigned to overlapping times
  • Absence: person marked unavailable for a date/time pattern
  • HP-approved hours: allowed windows for non-full-time Teacher-members

Viewer guide — staff, leads, substitutes

No admin access needed. Use this when you only need to read the schedule.

  1. Open the live schedule

  4. Pick Day-wise, Cohort-wise, School-wide, or Teachers

Detailed views how-to (with screenshots)

Follow these steps on the live schedule. Red markers show where to click and what each area means.

Live schedule: ashwinmatta.github.io/iiis-school-schedule — staff password required on entry.

Step 0 — Open and unlock the staff lock screen

  1. Go to the live schedule link above.
  2. Enter the shared staff access password.
  3. Click Continue. You should see the timetable and the top control bars.

Step 1 — Learn the shared filters (used by every view)

  1. Find the filter row under the view buttons.
  2. Choose Month, then Week.
  3. Optional: set From / To to narrow the visible time range.
  4. Click Export view as PDF when you need a printable handout of the current view.
Shared filters: Month, Week, time From/To, and Export PDF.

Step 2 — Day-wise view (one day across cohorts)

  1. Click Day-wise in the top view buttons.
  2. Use the Day dropdown under it to pick Mon–Sun.
  3. Confirm Month/Week are set to the week you need.
  4. Read the schedule grid: time down the side, cohorts/content as cards.
  5. Click any session card to open details (who, time, activity).
Day-wise view — best for daily operations and “what’s happening today?”
Use Day-wise when: you need today’s coverage, transitions, or who is on a specific activity this afternoon.

Step 3 — Cohort-wise view (one or more cohorts across the week)

  1. Click Cohort-wise.
  2. Use the cohort chips/legend to turn cohorts on or off (Green / Yellow / Purple / Blue).
  3. Set Month and Week.
  4. Scan across the week columns for that cohort’s rhythm.
  5. Click cards for details, same as Day-wise.
Cohort-wise view — best for classroom/cohort planning across the week.
Use Cohort-wise when: you want one cohort’s full week, or to compare a couple of cohorts side by side.

Step 4 — School-wide view (compact whole-school picture)

  1. Click School-wide.
  2. Keep Month/Week set correctly.
  3. Use this denser layout for leadership overview, not detailed reading.
  4. Click cards when you need to drill into a specific block.
School-wide view — compact overview of the whole timetable.
Use School-wide when: you need a quick leadership snapshot or to spot gaps across cohorts at once.

Step 5 — Teachers view (one person’s schedule)

  1. Click Teachers.
  2. Open the Teacher dropdown and select a name.
  3. Set Month/Week.
  4. Read that person’s week in the main grid.
  5. Check chips above the grid for load / open slots (and HP badge if non-full-time).
Teachers view — personal timetable, load, and open slots.
Use Teachers view when: checking your own day, a substitute’s coverage, or whether someone is free.

Step 6 — Open session details

  1. In any view, click a colored session card.
  2. Review activity, time, cohort, and people.
  3. Close the dialog when done. (Edit appears only if an admin has unlocked the app.)
Session detail popup after clicking a card.

Teacher guide — your schedule

  1. Open the live schedule and enter the staff access password
  2. Click Teachers
  3. Select your name

Badges

  • Full-time — no HP window limits in the app
  • Non-full-time — only within HP-approved days/times

If your HP hours look wrong, contact a schedule admin. The app blocks assignments outside approved windows.

Detailed side-panel how-to (with screenshots)

This walks through every control in the right-hand Admin panel on the live schedule app. Red dots and arrows mark each feature.

Open the live schedule first, then follow these steps in order. Site hosting is handled by the site/technical admin — this guide is only for schedule data changes.

Map of the Admin side panel

Everything below lives in the right sidebar after you unlock.

Admin side panel overview — each numbered marker is explained below.

Step 1 — Unlock the Admin panel

  1. Open the live schedule and pass the staff access password.
  2. On the right, find Passcode.
  3. Enter the schedule admin PIN.
  4. Click Unlock.
  5. Status should change from “Locked — view only” to unlocked.
Passcode box + Unlock button at the top of the Admin panel.

Step 2 — Clone weeks (copy a template forward)

  1. Choose Clone from (source week).
  2. Choose to (destination week).
  3. Click Clone week to copy one week.
  4. Or click Clone all empty to fill every empty week from the template.
Cloning overwrites empty destination structure. Spot-check Day-wise and Teachers views after cloning.

Step 3 — Add an assignment

  1. Optionally set the Day in the main Day-wise box (shown as “Selected day”).
  2. Click Add assignment.
  3. Fill Cohort, Day, Start, End, Activity, Kind.
  4. Select Who (lead teachers) — hold ⌘/Ctrl for multiple.
  5. Optional: select Support adults.
  6. If a conflict or HP-window warning appears, fix it before saving.
  7. Click Save.
Add / Edit Assignment dialog fields.

To edit later: click a session card → Edit. To remove: Edit → Delete.

Step 4 — Holidays for the selected day

  1. Select the day in the main Day dropdown.
  2. Confirm the sidebar note shows that day.
  3. Click Mark holiday or Clear holiday.

Step 5 — Delete day or week (destructive)

  1. Delete this day removes assignments for the selected day in the current week.
  2. Delete week removes the whole week’s data.
  3. Use only when sure — prefer cloning/fixing when possible.
Delete controls cannot be undone easily. Double-check the selected week/day first.

Step 6 — Teachers: add / remove / replace + HP hours

  1. In the sidebar Teachers section, click Add / remove / replace.
  2. To add: type a first name → Add teacher.
  3. To change future coverage: choose Teacher + From week onward → Replace… or Remove….
  4. Follow Bulk / Day by day / One by one / TBD options in the wizard.
  5. For non-full-time: set Employment to Non-full-time, then add HP-approved day/time windows.
Teachers dialog — roster changes and HP-approved hours.

Step 7 — Teacher absence

  1. Choose the teacher.
  2. Set Repeat: One day, Every week, or Every month.
  3. Fill the matching date / weekday / day-of-month field.
  4. Leave Full day checked, or uncheck and set From/To times.
  5. Click Add absence.
  6. Absences appear in the list under the form (can be removed from there).
Teacher absence controls in the Admin side panel.

Step 8 — File backups (for schedule admins)

  1. Download JSON for a data backup you can keep.
  2. Import JSON only when restoring a known-good backup.
  3. Download full HTML creates a complete file copy for the site/technical admin if they ask for it.
File tools at the bottom of the Admin side panel.
Schedule admins manage timetable data here. Publishing/hosting updates are done by the site/technical admin.

C. Common admin workflows

Build or refresh a week

  • Select source template week
  • Clone week or Clone all empty
  • Spot-check Day-wise and Teachers views

Add or edit an assignment

  • Add assignment (or Edit a card)
  • Set cohort, day, times, activity, Who, Support
  • Resolve conflict / HP-window messages before saving

Replace a teacher

  • Teachers → person → Replace…
  • Choose from-week onward
  • Bulk, Day by day, One by one, or leave TBD

Set non-full-time HP hours

  • Employment = Non-full-time
  • Weekdays + From/To → Add approved window
  • Confirm outside-window assigns are blocked

  • No unresolved conflicts on active weeks
